# Security policy

## Supported versions

Only the latest release receives security fixes. Older releases are not supported;
please update to the [latest release](https://github.com/leonatwork/Tappi/releases/latest).

## Reporting a vulnerability

Use **GitHub Private Vulnerability Reporting** to report a suspected security
vulnerability privately to the maintainer:

[Report a vulnerability](https://github.com/leonatwork/Tappi/security/advisories/new)
(repository **Security** tab ▸ **Report a vulnerability**).

Include the affected Tappi and macOS versions and a description of the potential
impact in your private report. Do not open a public issue or publish exploit
details while the report is being investigated.

This reporting route requires Private Vulnerability Reporting to be enabled in
the repository settings. If the reporting button is unavailable, the maintainer
needs to enable it; keep vulnerability details private.

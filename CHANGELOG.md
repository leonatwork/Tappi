# Changelog

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this
project adheres to [Semantic Versioning](https://semver.org/).

## [1.2.0] — 2026-10-12

### Added

- Interface in ten languages: English, German, French, Spanish, Italian, Portuguese
  (Brazil), Dutch, Japanese, Simplified Chinese and Korean. The *Language* submenu lists
  each in its own name; *System default* follows the macOS preferred languages and falls
  back to English.
- *More apps you might like* in the menu bar menu: Klemmi, Snapline and Snapboard, the other
  tools of the package *I love macOS, but I miss some Windows features*.
- App icon: a switcher panel with the middle window selected, generated by
  `scripts/generate-icon.swift` during `build.sh`.
- `scripts/check-localizations.swift` verifies that every language has every key, matching
  placeholders and lint-clean files.

### Changed

- Release builds are signed with a stable certificate, so granted permissions survive
  later updates. Updating from 1.1.0 needs one last re-grant.
- Strings moved from code into `Resources/<language>.lproj/Localizable.strings`. Existing
  `settings.json` files keep their language: `"english"` and `"german"` are read as before,
  and a language code such as `"fr"` or an unknown value no longer breaks the file.
- Diagnostics lines that tell you what to do (re-adding Tappi under Accessibility, granting
  Screen Recording from the menu) are written in the interface language and name the menu
  item as you see it.
- README: new section on the package; Homebrew instructions removed, since the tap is no
  longer public. Download the release or build from source instead.

## [1.1.0] — 2026-10-12

### Added

- Interface language setting: *System default*, *English* or *Deutsch*. Contributed by
  @CommanderTvis.
- *Tiles per row* in the menu bar menu, so every setting is reachable without editing
  `settings.json`.

### Changed

- *Open settings file* uses the default text editor instead of the app registered for
  JSON, which is often Xcode or a browser. Falls back to TextEdit, then Finder.
- Hand edits to `settings.json` take effect the next time the menu opens, without a restart.

### Fixed

- Changing a setting in the menu no longer overwrites edits made to `settings.json` by hand.
- While Tappi is running, a `settings.json` that does not parse is ignored instead of
  resetting every setting to its default.

## [1.0.0] — 2026-08-25

First release.

### Added

- Window switching modelled on Windows Alt-Tab: between **windows** rather than apps, in
  MRU order, with index 1 preselected — so a quick press switches to the last used window.
- Re-ordering only on release, which is what makes toggling back and forth between two
  windows work.
- <kbd>⌘</kbd><kbd>Tab</kbd> by default; the system switcher is taken over while Tappi is
  able to do the job, and handed straight back otherwise.
- <kbd>⌘</kbd><kbd>`</kbd> for windows of the current app (ISO and ANSI layouts).
- <kbd>⇧</kbd> to cycle backward, arrow keys, <kbd>Esc</kbd> to cancel, <kbd>⌃</kbd> for a
  sticky list, mouse control including "✕" to close a window.
- Live previews via ScreenCaptureKit, loaded asynchronously — the panel never waits.
- Menu bar settings: modifier, show delay, tile size, previews, minimized windows, other
  Spaces, hidden apps, mouse selection, launch at login.
- Diagnostics log and single-instance guard.

### Performance

1.0–1.7 ms from keypress to visible panel with 12 windows and previews enabled; about
0.6 % CPU time when idle.
